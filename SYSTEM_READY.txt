================================================================================
                         TROUBLESHOOTING
================================================================================

If motors not moving:
→ Check GPIO connections (BCM 12,5,6,13,26,16)
→ Verify L298N power supply
→ Run: python3 -c "from actuators.motor_controller import *; get_motor_controller()"

If servos not working:
→ Start pigpiod: sudo pigpiod
→ Check servo pins (BCM 18,23,24)
→ Run: python3 -c "from actuators.multi_servo_controller import *"

If sensors not reading:
→ Check wiring (DHT:4, Ultra:27/22, PIR:17, MQ3:26)
→ Test individually: python3 sensors/<sensor>_test.py
→ Enable MQ3: export MQ3_ENABLED=true
